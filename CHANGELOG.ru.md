## Unreleased

- README и CHANGELOG имеют английские основные и русские версии с переключением. AGENTS.md поддерживается в одном английском экземпляре с правилами синхронного обновления обеих языковых версий. AGENT-USAGE.md и генерируемая инструкция проекта по умолчанию английские; русское руководство сохранено отдельно.
- Добавлены Windows CI, проверка архивов и автоматизация черновиков релизов по тегам. Исторические версии привязаны к исходным коммитам и SHA-256 готовых VSIX. Лицензионный review сохраняется.
- Автоматический выбор языка учитывает встроенные и импортированные переводы; неподдерживаемая локаль использует английский, явный выбор сохраняется.

- В конец README добавлены ссылки на MIT и сторонние лицензии, а также русская и английская оговорка о товарных знаках Siemens и независимости проекта. Названия продуктов используются для обозначения совместимости.

- Переводы перенесены в `language/interface_en_us.json` и `interface_ru_ru.json`. Встроенные языки автоматически обнаруживаются при сборке; файлы `package.nls*.json` создаются из общего источника.
- Добавлены выбор языка интерфейса и импорт личных переводов без сборки. Отсутствующие строки используют стандартный английский перевод; пользовательские файлы сохраняются отдельно от каталога расширения. Повреждённые JSON и подстановки отклоняются.
- Исправлены подписи выпадающих списков настроек: отображаются переводы, а сохранённые технические значения остаются совместимыми.
- Пакеты VSIX выводятся в `releases/`; обновлены инструкция и пути package/upgrade-проверок. Новый VSIX не выпускается до закрытия вопросов Toolbox.

- Оригинальный код: MIT с указанием Cody и профиля Svyatogor3757; добавлены AUTHORS.md, инструкция по лицензиям, версии и атрибуция сторонних компонентов.
- Сохранены полные license/notice-файлы зависимостей и отдельная коллекция legal-файлов инструментов сборки. Добавлен инвентарь NuGet/npm с контрольными суммами DLL и уведомлений; development-only коллекция исключена из VSIX.
- В Git отключена нормализация legal-файлов `third-party/`, чтобы сохранять исходные CRLF/BOM и воспроизводить контрольные суммы.
- Toolbox 4.4.10 закреплён исходным Git-подмодулем. Для каждой части описаны найденные MIT/LGPL/Library GPL/CPOL обозначения и нюансы. Лицензия оригинального DBF-кода установлена как CPOL 1.02 по архивной статье Brian Duke; полный текст сохранён. Совместимость условий и подготовленная LGPL-поставка исходников пока не подтверждены. Эти вопросы документированы; упаковка нового выпуска блокируется до их обоснованного устранения. Локальная компиляция и тестирование доступны.

## 0.1.3 — 2026-11-24

- Щелчки по нативному проекту и представлению теперь открывают проводник VS Code. Если путь уже входит в workspace, используется наиболее подходящий существующий корень; иначе нужная папка добавляется в текущее окно без замены остальных.
- Добавление папки ожидает подтверждения VS Code. Для перехода из пустого окна или режима одной папки сохранён незавершённый переход на время перезапуска Extension Host. Отменённая или удалённая папка автоматически не открывается повторно.
- Исправлен выбор активного представления после его добавления в workspace. Отсутствующий путь сообщает об ошибке без перехода к посторонней папке.
- Сохранено закрытие проекта, когда в workspace больше нет содержащих его представление папок. Удержание закрытых проектов вне workspace не добавлялось. Явный пункт контекстного меню для проводника Windows сохранён.

## 0.1.2 — 2026-11-23

- Убрана постоянная инструкция «Сохранить файлы → Проверить изменения…» над деревом.
- Добавлена команда «Показать управление проектом» в палитре и заголовке дерева. Она раскрывает группу управления без сброса остальных панелей VS Code.
- Заголовки двух групп явно задаются на языке интерфейса. Добавлена проверка запуска с профилем, в котором ранее была открыта панель версии 0.1.0.
- В инструкции по установке уточнён перезапуск окна после обновления VSIX: обычное обновление проекта не перезагружает регистрацию интерфейса расширения.

## 0.1.1 — 2026-11-23

- Убрана приписка Step7Project у команд. Добавлены английский и русский интерфейсы с выбором по языку VS Code.
- Вместо скрытых действий заголовка добавлены две стандартные группы: «Управление проектом» и «Проект». Все пять основных действий доступны отдельными строками.
- В управлении показаны активный нативный проект и представление, полные пути в подсказках, переходы и контекстное копирование путей. Несколько проектов поддерживают ручной выбор и переключение по открытому файлу.
- Готовые представления автоматически находятся по step7project.json внутри рабочей области. Команда открытия принимает как нативный проект, так и манифест; найденные связи запоминаются только в пользовательском состоянии расширения.
- Новые представления сохраняют относительный путь к нативному проекту, если возможно. Добавлены настройка и CLI для выбора относительного/абсолютного пути. Старые абсолютные привязки сохранены. Служебный launcher обновляется при открытии, пользовательские скрипты не перезаписываются.
- Новые таблицы называются Symbols.csv/ASC без повторного суффикса. Старые имена поддержаны; повторный выбор текущего формата сокращает имя после закрытия редакторов, без потери неприменённых правок и без перезаписи чужого файла.
- Усилены проверки имён Sources: длина до 24 символов, запрещённые имена и символы Windows, дубликаты. Переименование исходника не меняет номера блоков и ссылки в коде. Исправлено создание DB после отмены выбора его типа.

## 0.1.0 — 2026-11-21
