# Изменения

## 0.1.1 — 2026-11-23

- Убрана приписка Step7Project у команд. Добавлены английский и русский интерфейсы с выбором по языку VS Code.
- Вместо скрытых действий заголовка добавлены две стандартные группы: «Управление проектом» и «Проект». Все пять основных действий доступны отдельными строками.
- В управлении показаны активный нативный проект и представление, полные пути в подсказках, переходы и контекстное копирование путей. Несколько проектов поддерживают ручной выбор и переключение по открытому файлу.
- Готовые представления автоматически находятся по step7project.json внутри рабочей области. Команда открытия принимает как нативный проект, так и манифест; найденные связи запоминаются только в пользовательском состоянии расширения.
- Новые представления сохраняют относительный путь к нативному проекту, если возможно. Добавлены настройка и CLI для выбора относительного/абсолютного пути. Старые абсолютные привязки сохранены. Служебный launcher обновляется при открытии, пользовательские скрипты не перезаписываются.
- Новые таблицы называются Symbols.csv/ASC без повторного суффикса. Старые имена поддержаны; повторный выбор текущего формата сокращает имя после закрытия редакторов, без потери неприменённых правок и без перезаписи чужого файла.
- Усилены проверки имён Sources: длина до 24 символов, запрещённые имена и символы Windows, дубликаты. Переименование исходника не меняет номера блоков и ссылки в коде. Исправлено создание DB после отмены выбора его типа.

## 0.1.0 — 2026-11-21

- Добавлена вкладка Step7Project с программами CPU, Sources, Blocks и Symbols.
- Добавлены обычные файлы UTF-8, пути для ИИ, CLI и инструкции AGENTS.md.
- Добавлены создание исходников OB/FC/FB/DB/UDT, компиляция, переименование и явное удаление.
- Добавлены CSV/ASC и табличный редактор symbols, включая VAT без типа данных.
- Добавлены режимы резервирования, восстановление в новый путь, staging, конфликты и recovery.
- Добавлен x86 backend для STEP 7 Classic и desktop bridge для Windows Remote SSH.
- Добавлен выбор английской/немецкой мнемоники AWL отдельно для каждого проекта.
- Таблицы symbols с дополнительными нативными атрибутами защищены от потери данных режимом только чтения.
